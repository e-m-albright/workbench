# Workbench documentation

This directory owns the current Workbench implementation, operational contracts,
and decisions. Architecture explains the shape; configuration explains deployment
and drift; agents describes the configured harnesses; security states the enforced
boundary and accepted limits. Experiments and decisions retain their own lifecycle.

Portable engineering guidance and technology research belong in the
[playbook](../playbook/README.md). Keep current operating facts here and link to
them from research instead of maintaining another configuration snapshot.
