# Systems

The services and infrastructure that applications and development environments
depend on: data stores, retrieval, hosting, provisioning, security, and workstation
tools. Use the topic named by the requirement, then compare vendors within it.

The services guide provides selection context; focused pages own detailed
comparisons. Agent-specific credentials, tool permissions, and execution belong
in [agents](../agents/README.md). The host repository owns actual workstation
installation and configuration.
