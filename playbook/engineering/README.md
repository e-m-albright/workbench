# Engineering

How to design, verify, review, document, and deliver software. These practices
apply across languages and projects. Build services, version control, performance
tools, command-line interfaces, and vendor ownership belong here when the
decision concerns the engineering workflow.

[Languages](../languages/README.md) own ecosystem-specific implementation advice.
[Systems](../systems/README.md) own the services an application runs on. A skill
owns the executable procedure for applying a practice; these pages own its
rationale and supporting evidence.
