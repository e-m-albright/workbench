# Agents

How model-driven systems reason, retrieve context, use tools, and act. Filenames
name the capability: harnesses, orchestration, interfaces, integrations,
assistants, security, evaluation, memory, and application frameworks. Models and
prompting have their own subdirectories.

Keep vendor evidence beside the capability it informs. General software
verification belongs in [engineering](../engineering/README.md); application
infrastructure belongs in [systems](../systems/README.md). Workbench's installed
behavior is documented in [docs/agents](../../docs/agents/README.md).
